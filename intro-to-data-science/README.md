# Intro to Data Science: pandas & NumPy Exercises

Exercises from **SCC0275 Introduction to Data Science** (USP, 2021), written as Google Colab notebooks and exported to `.py`. The questions and comments are in Portuguese.

| File | Dataset | What it covers |
|---|---|---|
| [`iris_exploration.py`](iris_exploration.py) | Iris (UCI) | Loading and naming columns, per-attribute and per-class histograms, derived columns (unit conversion), class counts, min/max by class |
| [`descriptive_stats_football.py`](descriptive_stats_football.py) | Classroom grades · European football players (Kaggle) | Why the mean alone misleads (spread, outliers), unit conversion (lb → kg), aggregations, filtering and summary statistics with pandas |

Run them in Colab or locally with `pip install pandas numpy matplotlib seaborn`. The data files are loaded from the paths at the top of each script.
